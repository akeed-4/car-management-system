🚀 HOW TO USE

═══════════════════════════════════════════════════════════════════════════════════

1. CHART OF ACCOUNTS
   ├─ From Menu: Setup → الشجرة المحاسبية
   ├─ Direct URL: http://localhost/setup/chart-of-accounts
   ├─ Actions:
   │  ├─ View: Expand/collapse nodes to see hierarchy
   │  ├─ Add: Click "+ Add Account" button
   │  ├─ Edit: Click edit icon on any account row
   │  └─ Delete: Click delete icon (if no children)
   └─ Sample data loads automatically

2. SALES RETURNS (ENHANCED)
   ├─ From Menu: Sales → مرتجعات المبيعات
   ├─ Direct URL: http://localhost/sales/returns
   ├─ Actions:
   │  ├─ Fill in: Invoice selection
   │  ├─ Enter: Return reason (min 10 chars)
   │  ├─ Check: Deposit refund checkbox (optional)
   │  ├─ Review: Auto-calculated refund amounts
   │  └─ Submit: Form sends to approval
   └─ Status automatically set to PENDING_APPROVAL

3. APPROVE SALES RETURNS (NEW)
   ├─ From Menu: Sales → اعتماد مرتجعات المبيعات
   ├─ Direct URL: http://localhost/sales/returns-approval
   ├─ Actions:
   │  ├─ View: List of pending approvals
   │  ├─ Select: Click a return to view details
   │  ├─ Review: Check reason and refund amounts
   │  ├─ Decide: Click Approve or Reject
   │  └─ Track: View approval history
   └─ Requires Manager role
