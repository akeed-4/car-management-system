🎯 QUICK ACCESS GUIDE

═══════════════════════════════════════════════════════════════════════════════════

TO VIEW CHART OF ACCOUNTS:
  1. Click: Setup menu → الشجرة المحاسبية
  2. Or navigate: http://localhost/setup/chart-of-accounts
  3. View 60+ sample accounts in hierarchy
  4. Use buttons: [+ Add Account] [Edit] [Delete]

TO CREATE A SALES RETURN:
  1. Click: Sales menu → مرتجعات المبيعات
  2. Or navigate: http://localhost/sales/returns
  3. Fill form with:
     - Select invoice
     - Enter reason (min 10 chars)
     - Optional: Check deposit refund
     - Review calculated refunds
  4. Click Save → Sent to manager for approval

TO APPROVE RETURNS (MANAGER):
  1. Click: Sales menu → اعتماد مرتجعات المبيعات
  2. Or navigate: http://localhost/sales/returns-approval
  3. View pending returns list
  4. Select return to review details
  5. Click Approve or Reject
  6. Return processes or goes back for revision
